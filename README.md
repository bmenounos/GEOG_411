# GEOG 411 lab data

Data files served through GitHub Pages for the GEOG 411 web labs.

- `Lab5/sites/<site>/tiles/` — lidar relief and hillshade map tiles (XYZ, WEBP)
- `Lab5/sites/<site>/elev/` — 2 m elevation grids, as compressed JS chunks

Source: LidarBC lidar DEMs (Province of British Columbia).
